# PWA 0.4.1 · легенда выбранного месяца

## Проблема и результат

Раскрываемая легенда перечисляла все варианты даже в месяце с одним типом смен. Галочка «Только выбранный месяц» включена по умолчанию. В этом режиме легенда показывает использованные в сетке цвета, смешанные фоны и отметки. При смене месяца обновляются строки, образцы и счётчик. Для пустого месяца показано сообщение «В этом месяце нет обозначений». Снятие галочки открывает полный справочник, включая остальные смешанные фоны и отметку смен коллег.

## Правила отображения

- Источник для краткой легенды — ячейки текущего месяца после применения ручных записей и отмен. Для смешанного фона показываются только отрисованные варианты. Если цвет личной записи замещает обычный фон, показывается фактический цвет.
- Ручные записи сопоставляются по типам и цветам видимых меток. Повторы убираются. Точка смен коллег входит в список, когда она видна в сетке. Для отмен показываются те символы, которые видны в данном месяце.
- Легенда расположена под сеткой календаря. Свёрнутая панель исключается из обхода клавиатурой. Образцы используют стили ячеек и меток в обеих темах.

## Данные и перенос в APK

Настройка `legendMonthOnly` — булево значение в существующем хранилище `settings` IndexedDB. При отсутствии значения действует режим выбранного месяца. Схема базы и формат резервной копии v3 сохранены. Новый ключ принимается при восстановлении, старые копии без ключа используют значение по умолчанию. Для вычисления легенды достаточно локального состояния, доступ к сети не требуется.

В APK сохранять переключатель в настройках интерфейса с тем же значением по умолчанию. Формировать краткий список из уже вычисленной модели ячеек текущего месяца, включая видимые ручные метки, отмены и точку коллег. Использовать цвета темы календаря. Оставить возможность открыть полный справочник даже в пустом месяце.

## Проверки

Браузерные сценарии покрывают переход между месяцами, пустой месяц, ручную заметку с выбранным цветом, смену смешанного фона после отмены и восстановления, полный режим, обе темы на 320 px, перезагрузку без сети и восстановление настройки из резервной копии. История обновлений проверяет раскрытую текущую версию при обычном и offline-запуске.

Локально прошли 139 unit-тестов и 24 браузерных сценария на production-сборке. Тест с необязательным внешним PDF пропущен. Сборка с `VITE_BASE=/duty/` и `git diff --check` прошли.
