# PWA 0.3.2 — читаемая таблица нагрузки сотрудников

Дата: 30.10.2026. Только PWA. Дополнение к [0.3.1](pwa-0.3.1-android-handoff.md) и [базовой спецификации рейтинга](employee-workload-android-handoff.md). Использовать вместе с ними при переносе в Android.

## Поведение и оформление

Проблема: колонка места занимала слишком много пространства, заголовок сортировки выглядел большой отдельной кнопкой, числа общей суммы находились близко к правому краю. Разная высота собственной строки и длинное пояснение мешали быстро сравнивать сотрудников.

- Четыре колонки: **№ / D-номер / Месяц / Всего**. В PWA ширины составляют 10 / 30 / 30 / 30%. «№» имеет доступное имя «Место в рейтинге».
- Над заголовками подпись **«Часы · сентябрь 2026 г.»** с выбранным месяцем. Она объясняет единицы и сохраняет контекст при прокрутке.
- Внутренние отступы блока: 16 CSS px, на ширине до 340 px — 12. Ячейки имеют дополнительные отступы, поэтому правые значения не прижимаются к рамке.
- Числа выровнены по правому краю одинаковых внутренних блоков шириной до 64 px; используются табличные цифры. Числовые заголовки располагаются в таких же блоках. Дробные часы сохраняют запятую.
- Место — небольшим приглушённым текстом. D-номер — полужирным. Метка **«Вы»** стоит рядом с ним, а не отдельной строкой; при нехватке места допускается перенос.
- Собственная строка выделена мягким фоном, скруглениями по краям и тонкой акцентной линией слева. Текущий столбец сортировки выделен цветом и насыщенностью чисел.
- Оба числовых заголовка остаются кнопками с областью нажатия не ниже 44 CSS px. Активный заголовок отмечен **↓** и тонкой нижней линией; другой — **↕**, обозначающей возможность переключить критерий. Оба критерия сортируют по убыванию. Для клавиатуры сохранены фокус, видимый контур и `aria-sort`.
- Строки разделены тонкими линиями. Большая заливка активного заголовка убрана. Светлая и тёмная темы используют существующие цвета приложения.
- Под таблицей остаётся короткая инструкция переключения сортировки. Детальные правила открываются по **«Как считаются часы»**. Там объясняются одинаковые места при равных часах, деление переходящих смен по полуночи, исключение V/#, количество загруженных месяцев и неполнота данных на границах.
- Пометка **«2 из 3 мес.»** под общей суммой и предупреждение о неполном наборе D-номеров остаются видимыми, если применимы.
- Состояние раскрытой справки сохраняется при фоновой перерисовке и смене сортировки в том же месяце. При смене месяца/уходе с экрана действует прежнее сворачивание блока рейтинга. Выбранная сортировка сохраняется на устройстве.

Для Android воспроизвести визуальную иерархию, выравнивание чисел, отступы и удобные области нажатия в нативных единицах. Не переносить CSS px в физические пиксели. Раскрывающаяся справка — отдельное действие под таблицей; шапка всего рейтинга сохраняет обычное раскрытие одним нажатием.

## Файлы и совместимость

- `src/analysis-view.ts`: подпись, колонки и содержимое ячеек, обозначения сортировки, раскрывающаяся справка.
- `src/experience.css`: размеры, выравнивание, выделение строки/столбца, обе темы и узкий экран.
- `src/main.ts`: сохранение состояния справки при перерисовке текущего рейтинга.
- `e2e/app.spec.ts`: точный выбор внешнего summary при наличии вложенной справки и проверка сохранения обоих раскрытых блоков.

Формулы, состав рейтинга, порядок сортировки и зарплатные расчёты не изменены. Приложение **0.3.1 → 0.3.2**, IndexedDB **v5**, резервная копия **v2**. Миграция данных не требуется. Версия пакета обновляет `version.json` и revision service worker в существующей сборке. Для уже установленной PWA используется прежний механизм предложения обновления с сохранением локальных данных.
