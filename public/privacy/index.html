PWA «Мои смены»

Коротко: графики обрабатываются и хранятся на вашем устройстве. У приложения нет собственного сервера, принимающего PDF или данные графиков. Google Calendar используется только по вашему явному действию.

1. Локальная обработка и хранение

Загруженный PDF разбирается непосредственно в браузере. Сам PDF, его имя и хэш, распознанные графики и D-номера, выбранный D-номер, настройки приложения и сведения о синхронизации сохраняются в IndexedDB браузера на вашем устройстве.

Эти данные не отправляются разработчику. PWA не имеет собственного backend или базы данных для пользовательских PDF и графиков.

2. Хостинг, аналитика и отслеживание

Статические файлы приложения публикуются через GitHub Pages. При обычном открытии сайта поставщик хостинга может обрабатывать стандартные технические данные веб-запроса в соответствии со своими правилами. Приложение не добавляет рекламу, аналитику, tracking pixels и пользовательское отслеживание.

3. Необязательная интеграция с Google Calendar

Google-интеграция выключена по умолчанию. Она активируется только после явного действия пользователя и использует Google Identity Services в браузере без собственного backend.

Приложение запрашивает следующие разрешения Google OAuth:

  • calendar.events.owned — для создания, проверки, изменения и удаления событий смен в основном календаре пользователя;
  • userinfo.email — для определения выбранного Google-аккаунта и его повторного выбора без обязательного показа списка аккаунтов при каждой сессии.

В Google Calendar передаются только смены, синхронизацию которых пользователь отдельно просмотрел и подтвердил. Событие может содержать дату и время смены, длительность, тип или код смены, выбранный D-номер и техническую private metadata PWA. PDF целиком и графики других D-номеров в Google не передаются.

4. Какие данные Google приложение использует

Email выбранного Google-аккаунта хранится локально как настройка интеграции и используется как login_hint. OAuth access token хранится только в памяти текущего сеанса приложения и не записывается в IndexedDB, localStorage или иной долговременный storage.

Локально сохраняются идентификаторы созданных событий, их последняя синхронизированная версия и технические сведения, необходимые для сравнения изменений и предотвращения дублей. Эти сведения разделяются между выбранными Google-аккаунтами.

Приложение проверяет и изменяет только события, которые оно создало и однозначно пометило через extendedProperties.private. Оно не считает пересекающиеся личные события конфликтом и не изменяет посторонние события календаря.

5. Передача и использование данных Google

Данные Google используются только для предоставления описанной пользователю функции синхронизации смен. Они не продаются, не используются для рекламы, профилирования или обучения моделей и не передаются разработчику либо иным третьим сторонам через приложение. Передача происходит непосредственно между браузером пользователя и официальными сервисами Google.

Использование информации, полученной от Google APIs, соответствует Google API Services User Data Policy, включая требования Limited Use.

6. Управление и удаление данных

В настройках можно отключить Google Calendar, сменить Google-аккаунт, удалить созданные PWA события за выбранный месяц или удалить все отслеживаемые события PWA из Google. Удаляются только события, которые приложение может однозначно подтвердить как собственные.

Пользователь также может удалить отдельный локальный график или все локальные данные приложения. Удаление данных PWA не удаляет исходный PDF из папки загрузок или файловой системы устройства.

Локальные данные сохраняются на устройстве, пока пользователь не удалит их через приложение, не очистит данные сайта или не удалит PWA средствами браузера или операционной системы.

7. Offline-работа

После установки и кэширования приложение может открывать локальные графики и обрабатывать PDF без сети. Интернет требуется для загрузки приложения при первом посещении, получения обновлений и любых операций Google Calendar.

8. Изменения и связь

Эта политика будет обновляться, если изменятся функции приложения или способы использования данных. Вопросы о приложении можно задать через репозиторий проекта на GitHub.
